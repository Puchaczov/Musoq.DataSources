# Stable datasource patch releases for Musoq Core 17.0.23

Requires Musoq Core **17.0.23** and .NET 10 for runtime plugin archives.
Upgrade the host Core packages together before installing the new datasource versions.

Git and Roslyn can process records from lazy nested collections one at a time
during `CROSS APPLY` and `OUTER APPLY`. Git queries that read only the paths and
modes of patch changes can do so without loading the patch text.

Each registered datasource is available on NuGet and as a runtime plugin
archive for Windows x64, Linux x64, macOS ARM64, and Alpine x64.
